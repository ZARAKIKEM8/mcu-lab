# 引脚与接线表

## 主控与外设

| 功能 | 引脚 | 配置 |
|---|---|---|
| OLED SCL | PB6 | I2C1_SCL，开漏复用 |
| OLED SDA | PB7 | I2C1_SDA，开漏复用 |
| DRV8833 AIN1 | PA6 | TIM3_CH1，PWM |
| DRV8833 AIN2 | PA4 | 推挽输出，低电平 |
| DRV8833 STBY | PA5 | 推挽输出，运行时高电平 |
| 蜂鸣器 IO | PB12 | 开漏输出，低电平触发 |
| 时间加 | PB1 | 上拉输入 |
| 时间减 | PB10 | 上拉输入 |
| 调速 | PB11 | 上拉输入 |
| 启动 | PB0 | 上拉输入 |
| 板载 LED | PC13 | 推挽输出，低电平点亮 |
| SWDIO | PA13 | 调试接口 |
| SWCLK | PA14 | 调试接口 |

## 电源

- 开发板可由 USB 或 ST-Link 的 3.3 V 供电。
- DRV8833 的 VM 使用 USB 5 V。
- OLED 使用 3.3 V。
- 蜂鸣器使用模块标注电压，常见为 3.3 V 或 5 V。
- 开发板、DRV8833、OLED、蜂鸣器必须共地。

## 电机端

DRV8833 的 AOUT1、AOUT2 接直流电机两根线，不分正负；如果需要改变默认转向，交换这两根线即可。
